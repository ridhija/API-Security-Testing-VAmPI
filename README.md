# API Security Testing – VAmPI
A practical API security assessment of the VAmPI vulnerable REST API using Postman and Burp Suite.

## 📌 Project Overview
This project focuses on identifying and testing common API security vulnerabilities in the VAmPI vulnerable REST API. The testing was performed in a controlled local environment using industry-standard API security testing tools.

## 🎯 Objectives

- Understand API security testing methodologies.
- Identify common vulnerabilities in REST APIs.
- Test API endpoints for authentication and authorization issues.
- Analyze HTTP requests and responses.
- Perform security testing using Postman and Burp Suite.

## 🛠️ Tools Used

- Postman
- Burp Suite Community Edition
- VAmPI – Vulnerable REST API
- Python
- REST API / HTTP

## 🔍 Testing Performed

The project includes testing of different API endpoints, including:

- User Registration
- User Login
- User Information Retrieval
- User Update Operations
- User Deletion
- Authorization and Access Control Testing
- Error and Response Analysis

## 🧪 Testing Approach

The API endpoints were first tested using Postman to understand their functionality and responses. Burp Suite was then used to intercept and analyze HTTP requests and responses and to perform additional security testing.

Screenshots of the API testing activities using Postman and Burp Suite are included in this repository.

## ⚠️ Disclaimer

This project was performed in a controlled local lab environment using the intentionally vulnerable VAmPI application. It is intended for educational and cybersecurity learning purposes only.
